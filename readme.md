Apple Global Product Sales Dataset

The Apple Global Product Sales Dataset contains 11,500 simulated sales transactions for iPhone, iPad, Mac, Apple Watch, and AirPods accessories. It covers 47 countries, 514 cities, sorted by country → city → date (2022-2024).

About this dataset
This dataset simulates the real global sales ledger of Apple products. It includes cross-regional city-level transaction data across multiple continents, including different currencies, sales channels, and customer demographic information—ideal for retail analysis, market segmentation, price analysis, time series forecasting, and geographical visualization.

⚠️ All data is simulated and is only for educational/portfolio purposes.
It does not represent actual financial data from Apple.
